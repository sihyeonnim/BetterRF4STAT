개인정보 안내

적용 대상: BetterRF4STAT 0.1.1 · 시행일: 2026년 10월 7일

게시자 BongE는 BetterRF4STAT가 처리하는 정보와 사용 목적을 다음과 같이 안내합니다.

1. 브라우저에 저장하는 설정

수역별 어종 숨김 목록과 아이콘 표시 설정을 Chrome의 로컬 저장 공간(chrome.storage.local)에 저장합니다. 화면 필터링과 다음 실행 시 설정 복원을 위해 사용하며, 개발자 서버로 전송하거나 다른 기기와 자동 동기화하지 않습니다. 별도의 계정을 만들 필요가 없습니다.

2. 사이트에서 읽는 정보

한국어 RF4 STAT의 어종 통계(/fish/) 및 Catch 목록(/fishing/)에서 수역 이름, 어종 식별값, 관련 링크 구조를 읽습니다. 사용자가 선택한 수역·어종에 해당하는 행을 숨기기 위해 현재 페이지에서만 사용합니다. 개별 로그 상세, 게시글 내용과 사진은 수집하지 않으며 숨김 설정을 적용하지 않습니다. 계정 비밀번호, 쿠키, 결제 정보, 브라우저 방문 기록을 수집하지 않습니다.

3. 외부 이미지 요청

물고기 아이콘 표시가 켜져 있으면 브라우저가 RF4 STAT에서 사용하는 img.rf4spot.com의 이미지 주소에 HTTPS 요청을 보냅니다. 해당 제3자 이미지 서버는 IP 주소 등 일반적인 네트워크 요청 정보를 수신할 수 있습니다. 확장 프로그램은 요청에 숨김 설정이나 RF4 STAT 로그인 정보를 추가하지 않으며 referrerpolicy="no-referrer"를 사용합니다. 이 제3자 서버의 운영 및 보관 정책은 게시자가 통제하지 않습니다. ‘물고기 아이콘 표시’를 끄면 새 이미지 요청을 하지 않습니다.

4. 백업 파일과 보관 기간

설정 내보내기는 수역·어종 식별값과 아이콘 설정을 사용자가 선택한 로컬 JSON 파일로 저장합니다. 설정 가져오기는 사용자가 직접 선택한 파일만 읽습니다. 파일은 자동 업로드되지 않습니다. 다른 사람에게 파일을 전달하면 파일에 포함된 설정도 공유됩니다.

설정은 현재 크롬 프로필에 유지되며, 확장 프로그램을 삭제하거나 확장 프로그램의 저장 데이터를 삭제하면 제거됩니다. 직접 내보낸 백업 파일은 사용자가 별도로 삭제해야 합니다. 확장 프로그램 업데이트만으로 설정을 지우지 않습니다.

5. 판매·광고·분석

개발자는 사용자 설정이나 목록 정보를 판매하지 않고, 광고 또는 분석 추적을 위해 사용하거나 전송하지 않습니다. 확장 프로그램에는 개발자 서버 통신, 광고 삽입, 원격 실행 코드가 없습니다. 원본 RF4 STAT 웹사이트 자체의 데이터 처리는 해당 서비스의 안내를 따릅니다.

6. 이 안내 웹사이트

이 웹사이트는 GitHub Pages로 제공될 수 있으며 별도의 분석 스크립트나 외부 폰트를 사용하지 않습니다. 호스팅 제공자인 GitHub는 페이지 제공에 필요한 요청 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해 주세요.
